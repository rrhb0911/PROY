# Módulo: Salud y Bienestar — PROY (Futuro)

Seguimiento de sueño, HRV, peso, frecuencia cardíaca en reposo, estrés, citas médicas. Datos que ya genera TrainingPeaks/WKO5 y smartwatch.

## Conexiones futuras
- TrainingPeaks API (HRV, peso, sueño)
- Google Fit / Apple Health
- Citas médicas calendarizadas

## Estructura
```
salud/
├── metricas/          # Peso, HRV, RHR semanal
├── sueno/             # Horas, calidad, tendencias
├── citas/             # Médicas, odontológicas, exámenes
└── recursos/          # Suplementos, planes de alimentación
```
