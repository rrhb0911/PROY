# Módulo: Fiscal e Impuestos — PROY (Futuro)

Gestión de obligaciones tributarias: declaraciones de renta, facturación electrónica, deducciones, ingresos como independiente.

## Estructura
```
fiscal/
├── declaraciones/      # Historial de declaraciones
├── deducciones/        # Gastos deducibles agrupados
├── facturacion/        # Facturas electrónicas emitidas
├── calendario.md       # Fechas clave (declaración, vencimientos)
└── ingresos-anuales.md # Resumen por año fiscal
```

## Conexiones
- **FINANZAS**: ingresos freelance y gastos deducibles
- **PROYECTOS**: facturación a clientes
