# Módulo: Diario Personal — PROY (Futuro)

Journaling personal: reflexiones diarias, gratitud, aprendizajes, estado de ánimo. Entrada opcional por día.

## Estructura
```
diario/
├── 2026/
│   ├── enero.md
│   ├── febrero.md
│   └── ...
└── plantilla.md        # Template para entrada diaria
```

## Formato de entrada
```markdown
# 2026-07-01

## ¿Qué pasó hoy?
...

## ¿Qué aprendí?
...

## ¿Qué haría diferente?
...

## Estado de ánimo: 😊 😐 😢
```
